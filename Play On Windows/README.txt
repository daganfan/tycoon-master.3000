TYCOON MASTER 3000 - Windows
============================

HOW TO PLAY
1. Download this whole folder (both files must stay together):
     TycoonMaster3000.exe
     resources.neu
2. Double-click TycoonMaster3000.exe.

If Windows shows "Windows protected your PC":
   click "More info" -> "Run anyway". (The game isn't signed with a paid
   certificate, that's all.)

REQUIREMENTS
- Windows 10 or 11 (64-bit).
- Microsoft Edge WebView2, which is already installed on almost every
  Windows 10/11 PC. If the game window stays blank, install the free
  "WebView2 Runtime" from Microsoft, then try again.
- A graphics card that supports WebGL 2 (any PC from the last ~8 years).

SAVES
Your progress is saved automatically on this computer.

CONTROLS
Click the game to capture the mouse (Esc frees it)
Mouse look · WASD move · Shift sprint · Space jump · V 1st/3rd person
E use a screen / light switch / door / drawer · Esc step back from a screen
G or hold left mouse: grab and carry · scroll: push/pull · right click: drop
R stand things up · H set this spot as home · F flop · T skill tree · F3 FPS
