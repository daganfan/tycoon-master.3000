# Asset Credits

All visuals in the current build are **procedural**: textures (wood floor, plaster, fabrics, rug, sky, coin/bill/bag atlases, normal maps derived from height canvases) are drawn on canvas at runtime and models are built from primitives in code. Post-processing uses the three.js examples (MIT). No third-party assets are bundled yet.
